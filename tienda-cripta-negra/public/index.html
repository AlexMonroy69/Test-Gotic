Antes de entrar: en qué consiste

Esta página es un experimento educativo de ciberseguridad del instituto. Su objetivo es mostrarte, de forma transparente, cuánta información puede obtener un sitio web de ti con solo visitarlo. No es una tienda re al.

Qué datos se van a recoger

  • Tu dirección IP y tu ubicación aproximada según esa IP (ciudad/país).
  • Datos de tu dispositivo: navegador, sistema operativo, resolución de pantalla, idioma, zona horaria, memoria, núcleos, tarjeta gráfica y una "huella" del navegador (canvas fingerprint).
  • Tu ubicación GPS precisa — solo si aceptas el permiso que te pedirá el navegador.
  • Opcional: una foto (cámara o archivo), solo si tú decides activarla.
¿Por qué se recoge la IP y lo demás?

Para demostrar en clase cómo funciona el rastreo y el fingerprinting, y así aprender a defendernos (por qué el navegador pide permiso para el GPS, cómo una VPN cambia tu IP y cómo las extensiones anti-fingerprint rompen el rastreo). Los datos van a un panel privado del responsable del experimento y se usan únicamente con fines académicos.

Puedes no aceptar y salir. Si continúas, estás dando tu consentimiento informado para la recolección descrita arriba.
